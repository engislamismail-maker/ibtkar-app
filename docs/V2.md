# IBTKAR — V1 و V2

## الاتفاق
- **V1** = البرنامج الأساسي اللي شغالين بيه دلوقتي (`index.html` في جذر المشروع، تطبيق `com.ibtkar.app`، والبيانات في Firebase تحت `ibtkar_sync_v2`).
- **V2** = النسخة التجريبية (فولدر `draft/`، تطبيق منفصل `com.ibtkar.app.draft` اسمه "إبتكار تجريبي"، وبياناتها التجريبية تحت `ibtkar_draft_v1`).
- لما صاحب المشروع يقول **"ابعتلي V2" / "ابعتلي أبلكيشن فيرجن 2"** يبقى المقصود: انقل V2 يبقى هو الأساسي (الخطوات تحت)، وابعت الـ APK + نسخة الكمبيوتر.

## اللي في V2 (فوق V1)
- 🎙️ الكلام: حسابات أو أرشيف (ملاحظات للمشروع).
- 📋 إدارة المشاريع (مكان "تسعير سريع"): تسعير سريع، تسعير مطبخ، Coming soon.
- 📊 تقرير الأسبوع لكل مشروع (جداول + إيصالات بصورها) + ميل كل خميس: ملف PDF لكل مشروع اتشغل فيه.
- 🔗 صفحة العميل = نفس تقرير الأسبوع (بأجزاء يتحكم فيها) + الأسابيع اللي فاتت.
- 💰 دفعات العميل والتحصيل (متأخرات).
- 📚 أسعاركم الفعلية (كمية + وحدة في المصروف).
- ☀️ منبّه ٩ الصبح (صوت منبّه، مش الجمعة) + "شغل النهارده" (مشاريع، شغلانات، مين في الموقع، ملاحظة).
- 🔔 إشعارات اللي الشخص التاني سجّله + جرس بعدّاد في الرئيسية.
- الهوية البصرية IBTKAR GE 2026 (أيقونات Lucide في دواير روز، Blush، جداول، شريط فحمي).
- متوقف لحد ما يتصمم: خطوات/ترتيب البنود (مقترح: https://claude.ai/artifact/CyRWDtbDhDjj6GWU5zJr8o).
- اتشال: التقرير اليومي.

## خطوات النقل (V2 يبقى الأساسي)
1. `draft/index.html` → `index.html`، و `draft/portal.html` → `portal.html` (ولينك صفحة العميل يتعدل لمكانه الجديد).
2. رجّع مسارات البيانات للأساسي: `SYNC_PATH = 'ibtkar_sync_v2'`، وشيل قراءة `LEGACY_SYNC_PATH` من التجريبي، و `SYNC_META_KEY = 'ibtkar-sync-meta'`.
   - بيانات التجريبي (`ibtkar_draft_v1`) **مش بتتنقل** — دي تجارب.
3. غيّر مسارات `ibtkar_draft_feed` → `ibtkar_feed` و `ibtkar_draft_portal` → `ibtkar_portal` (في `index.html` و `portal.html` و `NotifyReceiver.java`).
4. شيل الشريط الأصفر "نسخة تجريبية" والعنوان "إبتكار تجريبي".
5. انقل `draft/android/*.java` و `draft/android/AndroidManifest.xml` لمكانهم في `android/` (نفس `com.ibtkar.app` عشان يتثبت كتحديث فوق V1).
6. ابني الأندرويد (`android-latest`) والكمبيوتر (`desktop-latest`)، وجرّب على نسخة من البيانات الحقيقية قبل الدمج في `main`.
7. قول لصاحب المشروع: حدّثوا الموبايلين والكمبيوتر في نفس اليوم، واتأكدوا إن قواعد Firebase سامحة بالمسارات الجديدة.
