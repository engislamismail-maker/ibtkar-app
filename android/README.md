# تطبيق إبتكار — أندرويد

ده غلاف أندرويد لنفس ملف `index.html` اللي في أول الريبو. أي تعديل على `index.html`
بيتبني تلقائي APK جديد على GitHub Actions.

## التنزيل
https://github.com/engislamismail-maker/ibtkar-app/releases/download/android-latest/ibtkar.apk

## التثبيت (أول مرة)
1. افتح ملف `ibtkar.apk` من الواتساب أو من التنزيلات.
2. لو ظهر "تثبيت التطبيقات من مصادر غير معروفة" → اسمح للواتساب/مدير الملفات بالتثبيت.
3. لو Play Protect قال "تطبيق غير معروف" → "تثبيت على أي حال".
4. افتح التطبيق، اعمل الرقم السري، والبيانات هتنزل لوحدها من Firebase.

## المزامنة
البيانات متخزنة في Firebase Realtime Database (`ibtkar_ops_state`) — نفس المكان اللي نسخة
الويب بتستخدمه — فكل الموبايلات اللي عليها التطبيق بتشوف نفس البيانات لحظيًا.
محتاج إنترنت عشان المزامنة؛ من غير نت التطبيق بيشتغل وبيرفع التعديلات أول ما النت يرجع.

## التحديث
نزّل الـ APK الجديد وثبّته فوق القديم (من غير ما تمسح القديم) — البيانات بتفضل زي ما هي.

## البناء يدوي
```
./android/scripts/prepare-web.sh
cd android && ./gradlew assembleRelease
```
